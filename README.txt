TERMUX:
1. Put this ZIP in your Android Download folder.
2. In Termux:
   termux-setup-storage
   cd ~/storage/downloads
   unzip global_cart_runner_website.zip
   cd global_cart_runner_website
   python -m http.server 8080

3. Open Chrome and visit:
   http://127.0.0.1:8080
